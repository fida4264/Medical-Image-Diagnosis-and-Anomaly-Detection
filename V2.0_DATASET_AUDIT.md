  1. `glioma` (1,800 images: 1,400 train, 400 test)
  2. `meningioma` (1,800 images: 1,400 train, 400 test)
  3. `notumor` (1,800 images: 1,400 train, 400 test)

* **Readiness Status:** **`READY_WITH_CONDITIONS`**
* **Required V2.0 Actions:**
  * Carve out a stratified 15% validation split (840 images, 210 per class) from the 5,600 training images.

### 2.2 Brain CT

* **Source Dataset:** Head CT Hemorrhage Dataset
* **Root Path:** `datasets/brain_ct/`
* **Storage Structure:** Images in `head_ct/`, labels in external CSV `labels.csv`
* **Total Image Count:** 200 `.png` images (`000.png` through `199.png`)
* **Metadata Schema:** `labels.csv` contains 200 rows with columns `['id', 'hemorrhage']`
  * Missing values: 0 in `id`, 0 in `hemorrhage`
  * ID range: 0 to 199 (100% matched to image filenames `000.png` to `199.png`)
* **True Class Distribution:**
  1. `hemorrhage` (`hemorrhage=1`): 100 images (50.0%) — scan IDs 0–99
  2. `normal` (`hemorrhage=0`): 100 images (50.0%) — scan IDs 100–199
* **Class Balance:** Perfectly balanced 1:1.
* **Label Status:** 200 / 200 images **`VALIDATED`**.
* **CRITICAL V1 DEFECT CONFIRMED:**
  * The V1 training and evaluation code completely ignored `labels.csv` and collapsed the dataset into a single class named `"head_ct"`, reporting a trivial 100% accuracy on 8 samples.
  * The existing saved model is clinically unusable.
* **Readiness Status:** **`REPAIR_REQUIRED`**
* **Required V2.0 Actions:**
  * Retrain model from scratch using the true binary labels (`hemorrhage` vs. `normal`).
  * Because $N=200$ is small, adopt 5-fold stratified cross-validation with heavy spatial and intensity augmentation to prevent overfitting.

### 2.3 Chest X-ray

* **Source Datasets:**
  1. **Primary Classification:** COVID-19 Radiography Dataset (`datasets/chest_xray/COVID-19_Radiography_Dataset/`)
  2. **Secondary Detection:** VinBigData (`datasets/chest_xray/vinbigdata/`) — **STATUS: HOLD**
* **Classification Image Structure:** Folder-based per class with separated `/images` and `/masks` subdirectories:
  * `COVID/`: 3,616 images, 3,616 masks
  * `Lung_Opacity/`: 6,012 images, 6,012 masks
  * `Normal/`: 10,192 images, 10,192 masks
  * `Viral Pneumonia/`: 1,345 images, 1,345 masks
* **Total Classification Images:** 21,165 `.png` images
* **Total Segmentation Masks:** 21,165 `.png` masks (100% paired with classification images)
* **Metadata Files:** 4 Excel metadata files present (`COVID.metadata.xlsx`, `Lung_Opacity.metadata.xlsx`, `Normal.metadata.xlsx`, `Viral Pneumonia.metadata.xlsx`).
* **Source Classes Verified:** Exactly 4 classes.
* **CRITICAL V1 DEFECT CONFIRMED:**
  * The V1 model and configuration included a spurious 5th class named `"unknown"`. Direct inspection of source directories and metadata proves that **no "unknown" class exists in the source data**. This was an artificial artifact of flawed unmapped handling in V1.
* **VinBigData Status:**
  * Contains 18,000 `.png` files (15,000 train, 3,000 test) formatted for object detection (bounding boxes in CSV).
  * Does not fit the image-level classification task and must remain on **`HOLD`**.
* **Readiness Status:** **`READY_WITH_CONDITIONS`**
* **Required V2.0 Actions:**
  * Exclude all 21,165 mask files from classification training.
  * Remove the spurious `"unknown"` class from configs and retraining pipelines.
  * Handle class imbalance (7.6:1 Normal to Viral Pneumonia) with class-weighted loss.

### 2.4 Histopathology

* **Source Dataset:** LC25000 (Lung and Colon Cancer Histopathological Images)
* **Root Path:** `datasets/histopathology/lung_colon_image_set/`
* **Storage Structure:** Nested directories:
  * `colon_image_sets/`:
    * `colon_aca/`: 5,000 images (`.jpeg`, 768×768 RGB) — Colon Adenocarcinoma
    * `colon_n/`: 5,000 images (`.jpeg`, 768×768 RGB) — Colon Benign/Normal
  * `lung_image_sets/`:
    * `lung_aca/`: 5,000 images (`.jpeg`, 768×768 RGB) — Lung Adenocarcinoma
    * `lung_n/`: 5,000 images (`.jpeg`, 768×768 RGB) — Lung Benign/Normal
    * `lung_scc/`: 5,000 images (`.jpeg`, 768×768 RGB) — Lung Squamous Cell Carcinoma
* **Total Image Count:** 25,000 images.
* **Class Balance:** Perfectly balanced (5,000 images per class, exactly 20.0% each).
* **Duplicates / Corruptions:** 0 duplicate filenames across classes, 0 non-image files, all images verified 768×768 3-channel RGB.
* **Methodological Risk:** LC25000 was created by cropping non-overlapping tiles from larger pathology whole slide images (WSIs). Random image-level splitting poses a risk of tile-level near-duplicate leakage.
* **Readiness Status:** **`READY`**
* **Required V2.0 Actions:**
  * Enforce strict deterministic train/val/test partitioning with persistent split manifests to prevent tile-level leakage.

### 2.5 Retina

* **Source Dataset:** ODIR-5K (Ocular Disease Intelligent Recognition)
* **Root Path:** `datasets/retina/`
* **Metadata File:** `full_df.csv` (6,392 rows × 19 columns)
  * Unique Patient IDs: 3,358 patients
  * Patient Age: Range 1 to 91 years (mean: 57.9 years)
  * Patient Sex: 3,424 Male, 2,968 Female
* **Physical Directory Layout:**
  * `ODIR-5K/ODIR-5K/Training Images/`: 7,000 `.jpg` images
  * `ODIR-5K/ODIR-5K/Testing Images/`: 1,000 `.jpg` images (**UNLABELED competition test set**)
  * `preprocessed_images/`: 6,392 `.jpg` images (512×512 square crops)
  * Total physical images: 14,392
* **Cross-Reference & Label Ground Truth:**
  * `full_df.csv` precisely maps to **6,392 images** in `Training Images/`.
  * **608 images** in `Training Images/` have no metadata record (**`MISSING_LABEL`**).
  * All **1,000 images** in `Testing Images/` have no labels (**`MISSING_LABEL`**).
  * `preprocessed_images/` contains 6,392 images with filenames matching `full_df.csv`, but their preprocessing pipeline, color calibration, and cropping source are undocumented. Per Phase 1 instructions, these are classified as **`UNKNOWN_SOURCE`** and must be quarantined from supervised training.
* **True Task Formulation — MULTI-LABEL:**
  * Ground-truth labels are 8 binary indicators:
    * `N` (Normal): 2,101 (32.87%)
    * `D` (Diabetic Retinopathy): 2,123 (33.21%)
    * `G` (Glaucoma): 397 (6.21%)
    * `C` (Cataract): 402 (6.29%)
    * `A` (AMD): 319 (4.99%)
    * `H` (Hypertension): 203 (3.18%)
    * `M` (Pathological Myopia): 306 (4.79%)
    * `O` (Other Abnormality): 1,588 (24.84%)
  * Label Cardinality: 1 active label: 5,391 images (84.3%); 2 active labels: 955 images (14.9%); 3 active labels: 46 images (0.7%).
* **CRITICAL PATIENT LEAKAGE HAZARD:**
  * 3,034 patients have **both Left and Right eye images** in `full_df.csv`.
  * Standard random splitting splits left eye into train and right eye into test, yielding severe data leakage.
* **Readiness Status:** **`REPAIR_REQUIRED`**
* **Required V2.0 Actions:**
  * Convert task and model head from single-label multiclass to multi-label (`BCEWithLogitsLoss`).
  * Implement patient-grouped splitting (`GroupShuffleSplit` on Patient `ID`).
  * Quarantine `preprocessed_images`, `Testing Images/`, and the 608 unmapped training images.

### 2.6 Skin Lesion

* **Source Dataset:** HAM10000 ("Human Against Machine with 10,000 training images")
* **Root Path:** `datasets/skin/`
* **Metadata File:** `HAM10000_metadata.csv` (10,015 rows × 7 columns)
  * Missing metadata: 0 in `lesion_id`, `image_id`, `dx`, `dx_type`, `sex`, `localization`; 57 missing in `age`.
* **Physical Directory Layout:**
  * `HAM10000_images_part_1/`: 5,000 `.jpg` images
  * `HAM10000_images_part_2/`: 5,015 `.jpg` images
  * Overlap between parts: 0 (exact total: 10,015 unique images)
* **Metadata <-> Image Mapping:** Exactly 10,015 / 10,015 (100.0% match).
* **Diagnosis (`dx`) Class Breakdown (7 Classes):**
  1. `nv` (Melanocytic nevi): 6,705 (66.95%)
  2. `mel` (Melanoma): 1,113 (11.11%)
  3. `bkl` (Benign keratosis-like lesions): 1,099 (10.97%)
  4. `bcc` (Basal cell carcinoma): 514 (5.13%)
  5. `akiec` (Actinic keratoses / Bowen's disease): 327 (3.27%)
  6. `vasc` (Vascular lesions): 142 (1.42%)
  7. `df` (Dermatofibroma): 115 (1.15%)
  * **Imbalance Ratio:** 58.3:1 (`nv` vs `df`).
* **Ground Truth Validation Type (`dx_type`):**
  * Histopathology (`histo`): 5,340 (53.3%)
  * Follow-up examination (`follow_up`): 3,704 (37.0%)
  * Expert consensus (`consensus`): 902 (9.0%)
  * Confocal microscopy (`confocal`): 69 (0.7%)
* **CRITICAL V1 DEFECT CONFIRMED:**
  * In V1, `HAM10000_metadata.csv` was never merged into `master_metadata.csv`. All 10,015 skin images were recorded as `disease_class="unknown"`.
* **CRITICAL PATIENT / LESION LEAKAGE HAZARD:**
  * There are only 7,470 unique lesions across 10,015 images.
  * 2,545 images share a `lesion_id` with another image (up to 6 images per lesion).
  * Splitting by image allows identical lesions to leak between training and validation/test folds.
* **Readiness Status:** **`REPAIR_REQUIRED`**
* **Required V2.0 Actions:**
  * Perform inner join between image filenames and `HAM10000_metadata.csv` on `image_id`.
  * Implement lesion-grouped cross-validation (`GroupKFold` or `GroupShuffleSplit` on `lesion_id`).
  * Address 58.3:1 class imbalance via class weighting or focal loss.

### 2.7 Ultrasound

* **Source Dataset:** Dataset_BUSI_with_GT (Breast Ultrasound Images with Ground Truth)
* **Root Path:** `datasets/Ultrasound/Dataset_BUSI_with_GT/`
* **Directory Layout per Class:**
  * `benign/`: 891 total files
    * True classification images: 437
    * Segmentation masks: 454 (all paired with the 437 images; 17 images have multiple lesion masks e.g. `_mask_1.png`)
  * `malignant/`: 421 total files
    * True classification images: 210
    * Segmentation masks: 211 (all paired with the 210 images; 1 image has `_mask_1.png`)
  * `normal/`: 266 total files
    * True classification images: 133
    * Segmentation masks: 133 (100% 1-to-1 paired)
* **Totals:**
  * True classification images: **780 `.png` files**
  * Segmentation masks: **798 `.png` files**
  * Total files combined: 1,578
* **CRITICAL MASK CONTAMINATION RISK:**
  * If a generic loader (e.g. `ImageFolder`) scans the folders without filtering, all 1,578 files are ingested as classification images, doubling dataset size with binary masks.
  * Strict regex filtering (`not re.search(r'_mask', filename)`) is required.
* **Filesystem Case Sensitivity Issue:**
  * The directory is named `datasets/Ultrasound/` (uppercase `U`), but YAML configs reference `ultrasound` (lowercase `u`). On Linux/Docker, this causes `FileNotFoundError`.
* **Readiness Status:** **`READY_WITH_CONDITIONS`**
* **Required V2.0 Actions:**
  * Enforce strict mask exclusion for classification tasks.
  * Normalize directory path references or add case-insensitive resolution.
  * Use stratified splitting due to small dataset size (780 images).
