## 4. The 10-Step Hardened Inference Pipeline

| Stage | Letter | Description |
|-------|--------|-------------|
| 1 | A | Input Validation - format whitelist, size <= 20 MB, dimension bounds, pixel decoding |
| 2 | B | Modality Verification - exact match against 7 canonical modalities; no guessing |
| 3 | C | Preprocessing - ImageNet-normalised 224x224 RGB via ModalityAdapter |
| 4 | D | Baseline Forward Pass - ResNet-18 logits and penultimate features |
| 5 | E | Phase 7 Calibration - temperature scaling (multiclass) / per-label thresholds (Retina) |
| 6 | F | Phase 8 OOD Scoring - KNN/Mahalanobis/MSP/Entropy/Energy vs frozen thresholds |
| 7 | G | Phase 8 Anomaly Scoring - Mahalanobis distance from normal reference distribution |
| 8 | H | Quality Gate Evaluation - 7 sequential gates; failure triggers rejection or review |
| 9 | I | Audit Logging - SHA-256 image hash, masked patient tag, gate outcomes, metrics |
| 10 | J | Structured Response Assembly - StructuredInferenceResponse with full provenance |

## 5. Quality Gate Policy

| Gate | ID | Failure Effect |
|------|----|---------------|
| Input Validity | GATE_INPUT_VALIDITY | REJECTED_INVALID_INPUT (early exit) |
| Modality Validity | GATE_MODALITY_VALIDITY | REJECTED_UNSUPPORTED_MODALITY (early exit) |
| Model Availability | GATE_MODEL_AVAILABILITY | INFERENCE_ERROR (early exit) |
| Finite Outputs | GATE_FINITE_OUTPUTS | INFERENCE_ERROR (early exit) |
| Calibration Status | GATE_CALIBRATION_STATUS | FLAGGED_FOR_REVIEW (soft warning) |
| OOD Check | GATE_OOD_CHECK | REJECTED_OOD (hard) or FLAGGED_FOR_REVIEW (enforcement disabled) |
| Anomaly Check | GATE_ANOMALY_CHECK | REVIEW_REQUIRED_ANOMALY (never hard reject) |

**Quality Gate States:**
- ACCEPTED_FOR_MODEL_OUTPUT - All gates passed; prediction returned
- FLAGGED_FOR_REVIEW - Soft warning; prediction included with flag
- REVIEW_REQUIRED_ANOMALY - Anomaly detected; clinician review mandatory
- REJECTED_INVALID_INPUT - Input failed validation; no prediction
- REJECTED_UNSUPPORTED_MODALITY - Unknown modality; no prediction
- REJECTED_OOD - Input outside training distribution; no prediction
- INFERENCE_ERROR - Model/checkpoint failure; no prediction

## 7. Privacy-Conscious Audit Logging

Each inference call writes one JSONL record containing:
- `image_sha256`: SHA-256 hex digest (non-reversible; no pixels stored)
- `patient_pseudonym_tag`: HASH-<8-char-prefix> or ANONYMOUS (never raw ID)
- `quality_gate_status`: Gate decision enum value
- `is_abstained`: Boolean
- `rejection_reasons`: Structured list
- `ood_metrics`: method, score, threshold
- `anomaly_metrics`: score, threshold
- `error_code`: Optional error classification

Log writes are protected by threading.Lock() for concurrent safety.

## 10. Schema Bug Fix During Testing

During Phase 9 testing, a Pydantic V2 validation error was identified:

- **Root cause:** `anomaly_status` in `StructuredInferenceResponse` lacked a default.
  Early-exit abstained responses cannot pass this field, causing ValidationError.
- **Fix applied:** Added `default='UNAVAILABLE'` to `anomaly_status` in `pipeline_v2/schemas.py`.
- **Scientific impact:** None. Early-exit abstained responses correctly reflect UNAVAILABLE state.
  No model weights, calibration parameters, or threshold artifacts were modified.
