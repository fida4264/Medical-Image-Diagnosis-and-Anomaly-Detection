## 3. Calibration Methodology
**Method:** Post-hoc temperature scaling (Guo et al., 2017).

A single scalar temperature T is optimized to minimize Negative Log-Likelihood (NLL) on the **validation set only** using LBFGS optimization:

  `calibrated_prob = softmax(logits / T)`

ECE is computed using 15 equal-width confidence bins. The test set is never used to fit T. After T is frozen, the test set is evaluated exactly once.

## 8. Retina Threshold Methodology
Retina is treated as **independent multi-label classification** (8 sigmoid heads, NOT softmax). Default threshold = 0.50 for all labels.

**Optimization method:** For each label, sweep candidate thresholds from max_f1_validation_sweep (0.05–0.95, step 0.01) on validation data only. Select the threshold that maximizes per-label validation F1.

**Low-support labels** (hypertension, AMD, pathological_myopia): additionally compute Youden's J index threshold (argmax of sensitivity + specificity − 1). The threshold yielding higher F1 is selected.

After thresholds are frozen, the Retina test set is evaluated **exactly once**.

## 10. Cost-Sensitive Decision Analysis
> [!NOTE]
> This section presents **research decision analysis** only. No clinical recommendations, diagnostic thresholds, or clinical guidance are implied.

For each prioritized class, decision thresholds (0.10–0.90) were swept on validation data. Key findings:

- **Brain CT / hemorrhage:** Lowering threshold from 0.50 -> 0.30 raises sensitivity (recall) from ~0.96 -> ~1.00 at the cost of ~12 additional false positives.
- **Skin Lesion / melanoma:** Threshold 0.30 raises melanoma recall from 0.61 -> 0.82 but increases false positives substantially (precision drops ~0.30).
- **Ultrasound / malignant:** Threshold 0.35 yields recall ~0.92 with acceptable specificity (0.74).
- **Chest X-ray / lung_opacity:** Near-optimal at default 0.50; threshold 0.35 marginally improves recall (0.88 -> 0.93) with precision cost (~0.85 -> 0.79).
- **Retina / hypertension:** Threshold 0.20–0.25 required to achieve recall > 0.50 due to extreme class rarity.

## 11. Grad-CAM Methodology
**Method:** Gradient-weighted Class Activation Mapping (Selvaraju et al., ICCV 2017).

**Target layer:** `model.backbone[-1]` (ResNet-18 layer4, output shape: B×512×7×7)

**Computation:**
1. Forward pass records feature maps A from layer4
2. Backward pass for target class computes gradients dL/dA
3. Channel weights: α_k = global_avg_pool(dL/dA_k)
4. CAM = ReLU(Σ_k α_k · A_k)
5. Bilinear upsample to input size (224×224)
6. Normalize to [0, 1]; overlay with JET colormap (α=0.45)

**Sample categories per modality:**
- A: Correct + high confidence (score ≥ 0.80)
- B: Correct + low confidence (score < 0.50)
- C: **Incorrect + high confidence** (≥ 0.80) — highest clinical relevance
- D: Incorrect + low confidence (< 0.50)

Up to 5 samples per category, per modality. Model weights are NOT modified.

## 16. Limitations
1. **Temperature scaling is a global calibrator:** A single T per modality may not optimally calibrate all classes equally — minority classes may remain miscalibrated.
2. **Retina threshold tuning is label-independent:** Per-label thresholds do not model label co-occurrence dependencies.
3. **Grad-CAM spatial resolution:** ResNet-18 layer4 produces 7×7 feature maps before upsampling; fine spatial resolution cannot be claimed.
4. **Sanity analysis is heuristic:** The border/center classification is based on fixed spatial ratios with no anatomical ground truth.
5. **No clinical validation:** All models and outputs are research prototypes.
