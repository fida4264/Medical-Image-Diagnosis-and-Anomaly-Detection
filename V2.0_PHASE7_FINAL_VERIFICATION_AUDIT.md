## AUDIT 1 — Validation and Test Separation

### 1.1 Methodology & Code Trace
The source prediction tensors, manifests, and loader routines were traced through `run_v2_phase7.py`:
- **Fixed-split modalities** (`brain_mri`, `chest_xray`, `histopathology`, `retina`, `skin`):
  - `val_loader` was built with `split="validation"`.
  - `test_loader` was built with `split="test"`.
  - Temperature scaling and threshold optimization consumed `val_logits` exclusively.
  - Test sets were evaluated **exactly once** after parameters were frozen.
- **Cross-validation modalities** (`brain_ct`, `ultrasound`):
  - In `run_v2_phase7.py` (lines 185–202):
    ```python
    if split_type == "kfold":
        # Use fold 0 validation
        val_loader = _build_loader(split_file, split=None, fold=0,
                                   is_train_fold=False, task=task, num_classes=num_classes)
        val_logits, val_labels = _collect_logits(model, val_loader, task)
        # No separate test set for kfold — use fold 0 val as test proxy
        test_logits, test_labels = val_logits, val_labels
    ```

### 1.2 Analysis of Identical Values in Brain CT and Ultrasound
In the Phase 7 calibration report, Brain CT and Ultrasound exhibited identical validation and test metrics:
- **Brain CT:** Val NLL = Test NLL = $0.094098$; Val ECE = Test ECE = $0.058696$; Val Brier = Test Brier = $0.057701$.
- **Ultrasound:** Val NLL = Test NLL = $0.509461$; Val ECE = Test ECE = $0.078848$; Val Brier = Test Brier = $0.304935$.

**Forensic Determination:**
1. Neither `brain_ct_v2.0_folds.csv` nor `ultrasound_v2.0_folds.csv` contains an independent held-out `test` partition. Both are 5-fold cross-validation datasets (Brain CT: 200 total images; Ultrasound: 780 total images).
2. The pipeline author explicitly assigned `test_logits = val_logits` for k-fold modalities using Fold 0 validation (40 images for Brain CT, 156 images for Ultrasound).
3. Therefore, the reported test metrics are **not genuinely derived from an independent test partition**; they are identical copies of Fold 0 validation performance.

**Required Qualification:**
Publications and downstream documentation must state that Brain CT and Ultrasound were evaluated using **CV Fold 0 validation as a proxy** rather than an independent held-out test cohort.

## AUDIT 3 — Calibration Calculations

### 3.1 Mathematical Implementation Verification
The implementations in `calibration/v2_phase7/temperature_scaling.py` were audited against reference literature (Guo et al., 2017):
- **Temperature Scaling:** $p_{i} = \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}$ fitted via L-BFGS minimizing NLL on validation logits. Confirmed.
- **NLL Formulation:** $-\frac{1}{N} \sum_{n=1}^N \log(p_{n, y_n})$ with numerical clipping ($\epsilon=10^{-10}$). Confirmed.
- **Brier Score:** $\frac{1}{N} \sum_{n=1}^N \sum_{k=1}^K (p_{n,k} - y_{n,k})^2$ where $y_{n,k} \in \{0, 1\}$. Confirmed.
- **ECE & MCE:** 15 equal-width bins $[0, 1]$; $\text{ECE} = \sum_{m=1}^{15} \frac{|B_m|}{N} |\text{acc}(B_m) - \text{conf}(B_m)|$. Confirmed.

| **other_abnormality** | 173 | 192 | 0.32 | 0.4172 $\to$ 0.4435 | +0.0262 | 0.4557 $\to$ 0.4844 | +0.0287 | Stable |

### 4.2 Stability Risk Assessment
1. **Four Labels Assigned Extreme Thresholds ($\tau \ge 0.86$):** `cataract` (0.93), `amd` (0.93), `hypertension` (0.86), and `pathological_myopia` (0.92).
2. **Mechanism:** For imbalanced multi-label problems, uncalibrated sigmoid scores produce high false positive counts. The F1 optimization algorithm suppresses false positives by pushing thresholds toward 1.0, artificially boosting validation precision.
3. **Generalization Hazard (Hypertension Case Study):** On the test set, Hypertension true support is only 24 cases. At $\tau = 0.86$, only 6 positive predictions were made (3 true positives, 3 false positives), causing test recall to collapse to **$0.1250$** ($3/24$). Consequently, test F1 degraded from $0.2667 \to 0.2000$.
4. **Audit Recommendation:** In Phase 8, low-support labels should utilize **precision-recall break-even thresholds** or **constrained recall operating points** ($\text{Recall} \ge 0.50$) rather than pure unconstrained F1-maximization.
