# Module 3: Medical Image Preprocessing Framework

## Overview

Module 3 reads `metadata/master_metadata.csv` (generated by Module 2), identifies each
image's modality, applies the correct modality-specific preprocessing pipeline, saves
processed images to `processed_images/`, and generates full quality and history reports.

**Nothing is modified from Modules 1 or 2. No original files are touched.**

---

## Architecture

```
Factory Pattern + Abstract Base Class
─────────────────────────────────────────────────────────────────
run_preprocessing.py              (pipeline orchestrator)
  └─→ PreprocessorFactory.get(modality)
        └─→ BrainMRIPreprocessor   extends BasePreprocessor (ABC)
        └─→ BrainCTPreprocessor
        └─→ ChestXRayPreprocessor
        └─→ RetinaPreprocessor
        └─→ SkinPreprocessor
        └─→ UltrasoundPreprocessor
        └─→ HistopathologyPreprocessor
```

```
preprocessing/
├── base/
│   └── base_preprocessor.py    — ABC: preprocess(image) → (array, ops[])
├── common/
│   ├── image_loader.py         — OpenCV + PIL loader → BGR uint8
│   ├── image_validator.py      — 7 quality checks → flag list
│   ├── image_saver.py          — safe save with uint8 coercion
│   └── utils.py               — all shared image operations
├── pipelines/
│   ├── brain_mri_preprocessor.py
│   ├── brain_ct_preprocessor.py
│   ├── chest_xray_preprocessor.py
│   ├── retina_preprocessor.py
│   ├── skin_preprocessor.py
│   ├── ultrasound_preprocessor.py
│   └── histopathology_preprocessor.py
├── factory/
│   └── preprocessor_factory.py — registry → instantiation
└── reports/
    ├── quality_report.py       — QualityReportWriter (thread-safe)
    └── metadata_writer.py      — MetadataWriter (thread-safe)
```

## Modality-Specific Pipelines

### Brain MRI (`brain_mri`)

| Step | Operation |
|---|---|
| 1 | Convert BGR → Grayscale |
| 2 | Intensity normalize to [0, 255] |
| 3 | CLAHE (clip=2.0, grid=8×8) |
| 4 | Gaussian denoise (σ=1.0) |
| 5 | Replicate → 3 channels |
| 6 | Resize with padding → 224×224 |

Stubs: skull stripping, bias field correction (disabled; interfaces ready for future).

### Brain CT (`brain_ct`)

| Step | Operation |
|---|---|
| 1 | Convert → Grayscale |
| 2 | CT Windowing (WL=40, WW=80 — brain preset) |
| 3 | CLAHE |
| 4 | Gaussian denoise |
| 5 | Replicate → 3 channels |
| 6 | Resize → 224×224 |

### Chest X-Ray (`chest_xray`)

| Step | Operation |
|---|---|
| 1 | Convert → Grayscale |
| 2 | Intensity normalize |
| 3 | CLAHE (clip=3.0 — aggressive for low-contrast X-rays) |
| 4 | Gaussian denoise |
| 5 | Replicate → 3 channels |
| 6 | Resize → 224×224 |

Optional: histogram equalization (disabled by default, configurable).

### Retina (`retina`)

| Step | Operation |
|---|---|
| 1 | Circular crop (remove black border) |
| 2 | Green channel enhance (×1.2) |
| 3 | CLAHE in LAB space |
| 4 | Channel-wise brightness normalize |
| 5 | Intensity normalize |
| 6 | Resize → 224×224 |

### Skin Lesion (`skin`)

| Step | Operation |
|---|---|
| 1 | Channel-wise color normalize |
| 2 | CLAHE in LAB space |
| 3 | Intensity normalize |
| 4 | Resize → 224×224 |

Stub: hair artifact removal (disabled; interface ready).

### Ultrasound (`ultrasound`)

| Step | Operation |
|---|---|
| 1 | Convert → Grayscale |
| 2 | Intensity normalize |
| 3 | Median filter k=3 (speckle reduction) |
| 4 | CLAHE (clip=2.5) |
| 5 | Replicate → 3 channels |
| 6 | Resize → 224×224 |

### Histopathology (`histopathology`)

| Step | Operation |
|---|---|
| 1 | Channel-wise color normalize |
| 2 | Intensity normalize |
| 3 | Resize 768×768 → 224×224 (LANCZOS) |

Stub: Macenko/Vahadane/Reinhard stain normalization (requires reference image).

## Quality Checks

| Flag | Trigger |
|---|---|
| `empty` | All pixels identical (zero variance) |
| `too_dark` | Mean pixel < 20 |
| `too_bright` | Mean pixel > 245 |
| `too_small` | Either dimension < 32 px |
| `blurry` | Laplacian variance < 80 |
| `bad_channels` | Channel count not 1 or 3 |
| `corrupt` | Image cannot be loaded |

All thresholds are configurable in `configs/preprocessing.yaml → quality:`.

## Configuration

Edit `configs/preprocessing.yaml` to tune any parameter without code changes:

```yaml
general:
  target_size: [224, 224]
  num_workers: 8
  sample_mode: false
  skip_existing: true     # resume interrupted runs

quality:
  blur_threshold: 80.0
  dark_threshold: 20.0

modalities:
  brain_mri:
    clahe:
      clip_limit: 2.0
      tile_grid_size: [8, 8]
```

## Image Convention

All internal images are **BGR uint8 numpy arrays** (OpenCV convention).

- `ImageLoader.load()` always returns BGR uint8 regardless of source format
- All preprocessors consume BGR uint8 and return BGR uint8 `(224, 224, 3)`
- `ImageSaver.save()` accepts BGR uint8 and writes PNG/JPEG

---

## Thread Safety

- `PreprocessorFactory.get()` creates a new instance per call — safe for concurrent use
- `QualityReportWriter.record()` and `MetadataWriter.record()` use `threading.Lock`
- `ImageLoader`, `ImageSaver`, and all pipeline `preprocess()` methods are stateless

## Extending the Framework

### Add a new modality

1. Create `preprocessing/pipelines/new_modality_preprocessor.py` extending `BasePreprocessor`
2. Register in `preprocessing/factory/preprocessor_factory.py → _REGISTRY`
3. Add config section to `configs/preprocessing.yaml → modalities:`
4. Write tests in `tests/test_new_modality_preprocessor.py`

No other files need to change.
