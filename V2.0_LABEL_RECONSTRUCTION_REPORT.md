## 2. CANONICAL V2.0 METADATA SCHEMA

Every supervised record across all seven modalities conforms to the unified 22-column canonical schema defined in `metadata_manager/config.py`:

```
1.  image_id              : Unique string identifier (e.g. "MRI_TR_Tr-gl_0010", "CT_042", "SKIN_ISIC_0024306")
2.  image_path            : Relative POSIX path from project root (e.g. "datasets/brain_mri/Training/glioma/Tr-gl_0010.jpg")
3.  modality              : Canonical modality key ('brain_mri', 'brain_ct', 'chest_xray', 'histopathology', 'retina', 'skin', 'ultrasound')
4.  dataset_name          : Human-readable source dataset name
5.  dataset_version       : Modality version tag ('brain_mri_v2.0', 'brain_ct_v2.0', etc.)
6.  source                : Attribution source / archive (e.g. "Kaggle", "ISIC Archive", "IEEE DataPort", "LC25000")
7.  original_label        : Untouched raw label from original source (folder name, CSV code, or raw string)
8.  standardized_label    : Canonical standardized label name
9.  label_type            : 'multiclass', 'binary_classification', or 'multi_label'
10. class_id              : Integer class index (0..N-1) for multiclass/binary, or NULL for multi-label
11. multi_label_vector    : JSON serialized binary indicator array [N, D, G, C, A, H, M, O] for multi-label, else NULL
12. patient_id            : Patient identifier where determinable, else NULL
13. study_id              : Study / examination identifier where determinable, else NULL
14. lesion_id             : Lesion identifier for dermatology, else NULL
15. eye_id                : 'left' or 'right' for ophthalmology, else NULL
16. leakage_group_id      : Grouping key for non-leaking cross-validation (patient_id for retina, lesion_id for skin)
17. label_status          : 'VALIDATED' for all supervised records
18. metadata_source       : Provenance source ('folder_structure', 'labels.csv', 'HAM10000_metadata.csv', 'full_df.csv')
19. mask_status           : 'NONE' or 'PAIRED'
20. quality_status        : 'PASSED'
21. split_status          : 'train', 'test', or 'UNSPLIT'
22. duplicate_status      : 'UNIQUE', 'REPEATED_LESION', or 'NEAR_DUPLICATE_RISK'
```

### 3.2 Brain CT (`brain_ct_v2.0`)
- **Manifest:** `data/manifests/brain_ct_v2.0.csv` (200 records)
- **Label Source:** `datasets/brain_ct/labels.csv` joined to `datasets/brain_ct/head_ct/*.png` on scan ID.
- **Standardized Classes (2):**
  - `normal`: 100 images (class_id: 0, original_label: 0)
  - `hemorrhage`: 100 images (class_id: 1, original_label: 1)
- **Defect Repaired:** V1 completely ignored `labels.csv` and grouped all images under a single class `"head_ct"`. In V2.0, 100% of images are mapped to their true binary hemorrhage ground truth.

### 3.3 Chest X-ray (`chest_xray_v2.0`)
- **Manifest:** `data/manifests/chest_xray_v2.0.csv` (21,165 records)
- **Label Source:** `datasets/chest_xray/COVID-19_Radiography_Dataset/` classification subfolders.
- **Standardized Classes (4):**
  - `covid`: 3,616 images (class_id: 0)
  - `lung_opacity`: 6,012 images (class_id: 1)
  - `normal`: 10,192 images (class_id: 2)
  - `viral_pneumonia`: 1,345 images (class_id: 3)
- **Defect Repaired:** V1 included an artificial 5th class `"unknown"`. Source data contains zero unknown samples; this bug is completely eliminated in V2.0.
- **Quarantined:**
  - 21,165 paired segmentation masks in `/masks/` subdirectories (`label_status = MASK`).
  - 18,003 files from VinBigData (`label_status = HOLD`, object detection format).

- **Binary Target Vector Structure:** `[N, D, G, C, A, H, M, O]`

  - `diabetic_retinopathy`: 2,123 active cases
  - `glaucoma`: 397 active cases
  - `cataract`: 402 active cases
  - `amd`: 319 active cases
  - `hypertension`: 203 active cases

  - `other_abnormality`: 1,588 active cases
- **Patient Leakage Prevention:** `leakage_group_id` is populated with `patient_id` (3,358 unique patients) so both eyes from the same patient remain coupled during splitting.
- **Quarantined (8,000 images total):**
  - 1,000 ODIR-5K competition testing images (`MISSING_LABEL`)
  - 608 unmapped ODIR-5K training images (`MISSING_LABEL`)
